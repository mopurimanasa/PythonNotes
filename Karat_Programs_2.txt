0 -> 1

Permutation means arranging all the characters in every possible order.

Logic: 
-> Take "ABC".
-> Start with: path = ""
-> Choose A: - path = "A"
-> Now A is already used, so choose from B and C.
-> Choose B: -> path = "AB"
-> Only C remains: path = "ABC"
-> We got one permutation: - ABC
-> Now backtrack: remove the last choice and try another possibility.
-> 
ABC
ACB
BAC
BCA
CAB
CBA
-> Choose → Explore → Undo → Try another choice

Algorithm: 
-> Create an empty result list to store permutations.
-> Create a used array to remember which characters are currently used.
-> Start with an empty path.
-> Try every character in the string.
-> If the character is already used, skip it.
-> Otherwise, mark it as used and add it to path.
-> Continue recursively until path has the same length as the original string.
-> Add the completed path to result.
-> Backtrack: remove the character and mark it unused.
-> Continue until all possibilities are explored.

19) def permutations(text):
    result = []
    used = [False] * len(text)

    def backtrack(current):
        if len(current) == len(text):
            result.append(current)
            return

        for i in range(len(text)):
            if used[i] == False:
                used[i] = True

                backtrack(current + text[i])

                used[i] = False

    backtrack("")

    return result

Merge K Sorted Lists (arrays): Merge k sorted lists into one sorted list.

import heapq


def merge_lists(lists):
    heap = []
    result = []

    # Put the first element of each list into the heap
    for i in range(len(lists)):
        if lists[i]:
            heapq.heappush(heap, (lists[i][0], i, 0))

    # Continue until the heap is empty
    while heap:

        # Get the smallest value
        value, list_id, index = heapq.heappop(heap)

        # Add smallest value to result
        result.append(value)

        # Move to the next element in the same list
        next_index = index + 1

        # Check if the next element exists
        if next_index < len(lists[list_id]):

            # Get the next value
            next_value = lists[list_id][next_index]

            # Add the next value to the heap
            heapq.heappush(
                heap,
                (next_value, list_id, next_index)
            )

    return result


lists = [
    [1, 4, 7],
    [2, 5, 8],
    [3, 6, 9]
]

print(merge_lists(lists))

def decode_string(s):
    stack = []
    current = ""
    number = 0

    for char in s:

        # If it is a number
        if char.isdigit():
            number = number * 10 + int(char)

        # If we see [
        elif char == "[":
            stack.append((current, number))

            current = ""
            number = 0

        # If we see ]
        elif char == "]":
            prev_string, repeat_count = stack.pop()

            current = prev_string + current * repeat_count

        # If it is a normal character
        else:
            current = current + char

    return current


s = "3[a2[c]]"

result = decode_string(s)

print(result)
