1) Generate All Permutations of a String (unique characters)

Using itertools.permutations(): 

from itertools import permutations
n = input("Enter a string ")
for p in permutations(n):
    print("".join(p))
	
2) 
Merge K Sorted Lists (arrays): Merge k sorted lists into one sorted list.

def merge_lists(arrays):
    result = []
    for arr in arrays:
        result.extend(arr)
    return sorted(result)
    
arrays = [[1,2,4], [7,3,5], [8,3,3]]
print(merge_lists(arrays))
