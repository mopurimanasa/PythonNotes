5) Sum of digits of a number

Approach 1: Mathematical calculation
def sum_of_digits(num):
    total = 0 
    while num > 0:
        total = total + num % 10
        num = num // 10
    return total

num = 1234
print("summ of digit is ", sum_of_digits(num))

def sum_of_digits(num):
    total = 0
    
    for digit in str(num):
        total = total+int(digit)
    return total

9) Check if a number is prime - Check divisors up to sqrt(n)

What is a Prime Number?
A number bigger than 1.
It has only two factors: 1 and the number itself.
If you divide it by any other number, you get a leftover amount or a fraction. 

Examples of Prime Numbers
2: Only divided by 1 and 2 (it is the only even prime number).
3: Only divided by 1 and 3.
5: Only divided by 1 and 5.
7: Only divided by 1 and 7.
11: Only divided by 1 and 11.
13: Only divided by 1 and 13. 

Numbers That Are Not Prime
1: Not prime because it only has one factor (itself).
4: Not prime because it can be divided by 1, 2, and 4.
6: Not prime because it can be divided by 1, 2, 3, and 6.

Why only up to √n?

Suppose n = 36.
The factor pairs are:
1 × 36
2 × 18
3 × 12
4 × 9
6 × 6

After reaching 6 (√36), the factors start repeating in reverse:
9 × 4
12 × 3
18 × 2
36 × 1

So if there were a factor greater than √n, its matching factor would already have been found below √n. Therefore, checking beyond √n is unnecessary.

Algorithm
If n <= 1, it is not prime.
Loop from 2 to √n.
If any number divides n evenly (n % i == 0), it is not prime.
If no divisor is found, it is prime.


def is_prime(n):
	if n <= 1:
		return False
	
	for i in range(2, int(n ** 0.5)+1):
		if n % i == 0:
			return False
	return True

n = int(input("Enter a number "))
if is_prime(n):
	print("Is prime")
else:
	print("Is not prime")

11) Explaination:

Suppose we have these names:

HyderabadManasa
HyderabadRavi
HyderabadSuresh

Our goal is to find the town name.

Step 1: Take the first name as the prefix

Initially, we assume the whole first name is the town name.

prefix = HyderabadManasa

Now compare it with the second name.

prefix : HyderabadManasa
name   : HyderabadRavi

Do they match completely?

❌ No.

Because:

HyderabadManasa
HyderabadRavi
           ^

They differ after Hyderabad.

Step 2: Remove one character from the end

This line does the trimming:

prefix = prefix[:-1]

It removes the last character.

So:

HyderabadManasa

becomes

HyderabadManas

Compare again:

HyderabadManas
HyderabadRavi

Still not matching.

Trim again:

HyderabadMana

Compare again.

Still doesn't match.

Trim again:

HyderabadMan

Still doesn't match.

Continue trimming:

HyderabadMa

Still doesn't match.

Continue:

HyderabadM

Still doesn't match.

Continue:

Hyderabad

Now compare:

Hyderabad
HyderabadRavi

Does "HyderabadRavi" start with "Hyderabad"?

✅ Yes!

So we stop trimming.

Now:

prefix = Hyderabad
Compare with the third name

Now compare:

prefix = Hyderabad

name = HyderabadSuresh

Does it start with "Hyderabad"?

✅ Yes.

No trimming is needed.

Answer:

Hyderabad

====================================================

Algorithm: Find the Common Town Name (Longest Common Prefix)

Step 1
Read the number of people N and their names.

Step 2
Assume the first person's name is the common prefix.
prefix ← first person's name

Step 3
For each remaining name (from the 2nd person to the Nth person):
Compare the current name with the current prefix.
If the current name does not start with the prefix:
Remove the last character from the prefix.
Repeat until the current name starts with the prefix or the prefix becomes empty.

Step 4
Repeat Step 3 for all names.

Step 5
If the prefix becomes empty:

Print "No common town name found."
Otherwise:
Print the remaining prefix as the town name.

====================================================

Pseudocode:

Algorithm FindTownName(names, N)

Step 1: prefix ← names[0]

Step 2: For i ← 1 to N-1

            While names[i] does not start with prefix

                  Remove the last character from prefix

                  If prefix becomes empty
                        Return "No common town name"

Step 3: Return prefix

def find_town_name(names):
    
    prefix = names[0]
    for n in names[1:]:
        while not n.startswith(prefix):
            prefix = prefix[:-1]
            
    return prefix
    
    if prefix == "":
        return "No name is matching"
    
n = int(input("Enter the number "))
names = []
for i in range(n):
    name = input(f"Enter name {i+1} ")
    names.append(name)
    
print(find_town_name(names))

The inputs are D, which is the total distance to the school, K, which is John's initial energy, N, which is the number of juice stalls, and the position and juice quantity of 
each stall.

John starts at position 0 with energy K, and I initialize stops to 0. I sort the juice stalls based on their position from home.

For each next stall, I calculate the distance John needs to travel using next_position - current_position. For example, if John is at position 0 and the next stall is at 
position 6, he needs to travel 6 units, so he needs 6 units of energy.

Before traveling, I check whether John's current energy is sufficient to cover that distance. If it is not sufficient, I take the largest available juice amount from the 
previously reached stalls, add it to his energy, and increment stops by 1.

I continue this until John has enough energy to reach the next stall. If there is no available juice and his energy is still insufficient, I return -1.

Once he has enough energy, he travels to the next stall, so I subtract the traveled distance from his energy. Then I add that stall's juice to the available juice collection and 
update his current position.

I repeat the same process until John reaches the school. Finally, I return the number of juice stops.
